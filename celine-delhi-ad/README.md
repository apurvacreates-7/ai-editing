# Celine × Delhi Air — 18s 3D ad (1080×1920)

Sincere, emotional 3D spot: Delhi smog → mother & child in masks → a glowing Celine
Vitamin C tablet clears the haze and forms an immunity shield → free-sample end card.

Built with Remotion + Three.js (react-three-fiber). Score is generated in code (`scripts/gen-audio.mjs`).

```bash
npm install
node scripts/gen-audio.mjs   # regenerate public/music.wav
npm start                    # Remotion Studio preview
npm run render               # -> out/celine-delhi-ad.mp4
```

Storyboard (30fps): 0–3.5s aerial of India Gate in smog · 3.5–8.3s street-level family ·
8.3–10s tablet descends · 10s burst clears the sky · 10.5–13.3s shield + brand line · 13.3–18s pack shot + CTA.
